# 暗記アプリ「診断士 暗記ノート」計画・仕様書

最終更新: 2026-11-05

## 1. 目的

中小企業診断士試験の **問題・重要論点・公式・重要数式** を、Q&A形式（表＝問題 / 裏＝答え）のカードで反復練習し、
**間隔反復（スペースド・リピティション）** によって記憶を定着させる。手元のスマホで毎日使うことを前提にする。

## 2. 開発方針

| 項目 | 方針 | 理由 |
|---|---|---|
| アプリ形態 | **PWA（ホーム画面に追加できるWebアプリ）** | iPhone / Android のどちらでも同じアプリが動く。App Store / Google Play の審査・開発者登録が不要。URLを開いて「ホーム画面に追加」するだけでインストールできる |
| 技術 | HTML + CSS + JavaScript（ビルド不要・外部フレームワークなし） | 保守が簡単。GitHub Pages にそのまま置ける |
| データ保存 | 端末内（IndexedDB） | サーバー不要・オフラインで動作・通信費なし。画像もそのまま保存できる |
| 公開 | GitHub Pages（GitHub Actionsで自動デプロイ） | 無料のHTTPS配信。PWAに必要 |
| バックアップ | JSONファイルへの書き出し / 読み込み | データは端末内にしかないため、機種変更や事故に備える |
| 数式表示 | KaTeX（`$...$` で囲んだ部分を数式表示。アプリに同梱しオフラインでも表示） | 財務・会計の公式を見やすく表示する |

### 将来の拡張候補（今回は対象外）
- Capacitor でネイティブアプリ化（OSのローカル通知で完全に正確な時刻通知が可能になる）
- 複数端末間の同期（クラウド保存）
- 学習グラフの詳細化

## 3. データ構造

```
科目フォルダ（例: 財務・会計）
 └─ 単元（例: 経営分析 / CVP分析 / 投資の意思決定）
     └─ カード（問題 + 答え、各1枚まで画像）
```

### 3.1 フォルダ（folders）
| 項目 | 内容 |
|---|---|
| id | 一意ID |
| kind | `subject`（科目）/ `unit`（単元） |
| parentId | 単元の場合は所属する科目のID |
| name | 名前 |
| order | 並び順 |

### 3.2 カード（cards）
| 項目 | 内容 |
|---|---|
| id / unitId / subjectId | ID と所属 |
| q / a | 問題文 / 答え（各 **最大2,000文字**。要件の「約1,000文字」に余裕を持たせる） |
| qImg / aImg | 問題・答えそれぞれ画像1枚（images ストアのID） |
| state | `new`（未学習）/ `learning`（学習中）/ `review`（復習中）/ `mastered`（クリア） |
| level | 復習間隔の段階（0〜） |
| due | 次回の復習日（YYYY-MM-DD） |
| reviews / correct / lapses | 解答回数 / 正解回数 / 「もう一度」回数 |
| lastGrade / lastReviewed | 直近の評価と日時 |

### 3.3 画像（images）
カード本体と分けて保存（一覧表示を軽くするため）。撮影写真は自動で長辺1600pxに縮小・JPEG圧縮して容量を節約。

### 3.4 想定規模
1単元100枚以上、1科目数百枚、7科目合計で数千枚を想定。IndexedDB なので問題なく扱える。

## 4. 機能一覧

### 4.1 フォルダ・単元管理
- 科目フォルダの作成・名前変更・削除
- 科目内に単元を作成・名前変更・削除
- 各フォルダ・単元に「今日の復習枚数 / 総枚数 / クリア枚数」を表示
- 初回起動時に診断士7科目（経済学・経済政策 / 財務・会計 / 企業経営理論 / 運営管理 / 経営法務 / 経営情報システム / 中小企業経営・政策）をワンタップで作成可能

### 4.2 カード作成・編集
- 問題・答えを自由入力（改行可、文字数カウンター付き）
- 問題・答えそれぞれに画像1枚（カメラ撮影 / 写真から選択）
- `**太字**` で強調、`$...$` で数式（例 `$ROE = \frac{当期純利益}{自己資本}$`）
- **まとめて追加**：Excel / スプレッドシートから「問題[TAB]答え」の行を貼り付けて一括登録（100枚単位の登録に対応）
- カードの別単元への移動・削除・学習記録のリセット・手動でクリア/クリア解除
- 単元内のカード検索

### 4.3 学習（出題）
- 範囲：全体 / 科目 / 単元
- モード：
  - **今日の復習**（期限が来たカード + 新規カード）
  - **全カード**（期限に関係なく全部。クリア済みも含む）
  - **苦手のみ**（「もう一度」「難しい」を付けたことがあるカード）
- 問題 → 「答えを見る」 → 自己評価の4ボタン
- 出題順のシャッフル（設定でON/OFF）

### 4.4 自己評価と復習スケジュール（リマインド頻度）

| ボタン | 意味 | 次回の復習 |
|---|---|---|
| もう一度 | 解けなかった | **今日中**（このセッション内で数枚後に再出題。段階はリセット） |
| 難しい | なんとか解けた | **明日**（設定で日数変更可）。段階は進まない |
| 正解 | 解けた | 段階を1つ進める → 次の間隔 |
| 簡単 | 余裕 | 段階を2つ進める |

- 復習間隔の段階は **設定で自由に変更可能**（初期値：`1, 3, 7, 14, 30, 60` 日）
- 最後の段階を越えたら **クリア** 判定となり、通常の復習から外れる
- ボタンには「明日」「7日後」「クリア」など、押した場合の次回予定を表示
- 1日に新しく出題する新規カードの上限（初期値30枚）を設定可能

### 4.5 毎日20時のリマインド通知
Webアプリ（PWA）の通知はOSごとに制約があるため、**確実な方法を複数用意**する。

| 方法 | iPhone | Android | 確実性 |
|---|---|---|---|
| ① カレンダー登録（.ics）：毎日20:00のアラーム付き予定を標準カレンダーに追加 | ◎ | ◎ | **最も確実（推奨）** |
| ② アプリ内通知：アプリを開いている/バックグラウンドにある時、設定時刻に「今日の復習がN枚あります」と通知 | ○（ホーム画面追加 + iOS 16.4以上） | ○ | アプリが動作中の時のみ |
| ③ 定期バックグラウンド同期：Chrome（Android）でインストール済みの場合、OSの判断で1日1回程度起動して通知 | × | △ | 時刻はOS任せ |

- 通知時刻は設定で変更可能（初期値 20:00）
- 当日すでに通知済みなら重複しない

### 4.6 設定・データ管理
- 復習間隔、「難しい」の日数、新規上限、シャッフル、数式表示、通知時刻
- バックアップ書き出し（画像込みJSON）/ 読み込み（統合 or 全置き換え）
- 永続保存のリクエスト（ブラウザによる自動削除を防ぐ）と使用容量表示

### 4.7 ホーム画面
- 今日の復習枚数と「今日の復習を始める」ボタン
- 今日解いた枚数・連続学習日数
- 科目フォルダ一覧

## 5. 画面構成

```
ホーム ─┬─ 科目 ── 単元 ──┬─ カード編集
        │                  ├─ まとめて追加
        │                  └─ 学習（出題）→ 結果
        └─ 設定
```

## 6. 非機能要件
- スマホ縦画面に最適化（片手操作、大きなボタン）、ダークモード対応
- オフラインで動作（Service Worker によるキャッシュ）
- データは端末外に送信しない

## 7. 注意事項（重要）
- **必ず「ホーム画面に追加」して使う**：iPhoneのSafariでは、ホーム画面に追加していないサイトのデータは長期間未使用で削除されることがある
- データは端末内のみ。**定期的にバックアップ**を書き出す（設定画面から）

## 8. 構築ステップ
1. 仕様書作成（本書）
2. データ層（IndexedDB）・復習スケジュールロジック
3. 画面（ホーム / 科目 / 単元 / カード編集 / まとめて追加 / 学習 / 設定）
4. 通知・カレンダー登録・バックアップ
5. PWA化（manifest / Service Worker / アイコン）
6. GitHub Pages への自動デプロイ設定
7. 動作確認（ブラウザ自動テスト）

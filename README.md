# 診断士 暗記ノート

中小企業診断士の問題・重要論点・公式を、Q&Aカードと間隔反復で覚えるスマホ用暗記アプリ（PWA）です。

- 仕様書：[docs/SPEC.md](docs/SPEC.md)
- アプリ本体：[app/](app/)（HTML/CSS/JavaScript、ビルド不要）

## 主な機能
- 科目フォルダ → 単元 → カード（問題/答え 各2,000文字・画像1枚ずつ）
- まとめて追加（Excel/スプレッドシートから貼り付け）
- 自己評価4段階（もう一度＝今日 / 難しい＝明日 / 正解 / 簡単）と、自由に設定できる復習間隔・クリア判定
- 数式表示（`$...$`）・太字（`**...**`）
- 毎日20時のリマインド（カレンダー登録 / アプリ通知）
- オフライン動作、バックアップ書き出し・復元

## スマホで使えるようにする（GitHub Pages）
1. GitHub のリポジトリ → **Settings → Pages → Build and deployment → Source** を **GitHub Actions** にする
2. このブランチを `main` にマージする（または Actions タブで「Deploy app to GitHub Pages」を手動実行）
3. 公開URL（例：`https://<ユーザー名>.github.io/<リポジトリ名>/`）をスマホで開く
4. **ホーム画面に追加**
   - iPhone：Safari の共有ボタン →「ホーム画面に追加」
   - Android：Chrome のメニュー →「アプリをインストール」
5. アプリの「⚙︎ 設定 → カレンダー登録ファイルを作成」で、毎日20時のリマインドを登録

> 無料プランで GitHub Pages を使うには、リポジトリが Public である必要があります。
> データはスマホ内にのみ保存されます（URLが公開でも他人からは見えません）。
